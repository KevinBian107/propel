Tools

Claude Code and git are required. Codex is optional; without it Propel runs with one model.

    Optional plugins

    Propel uses these when they are present and works without them. propel init never installs them: a plugin can ship hooks, commands and MCP servers, so it runs code in your session. Whether to allow that is your decision.
