Propel is not an autonomous agent. It automates the tedious half of research engineering — tracing code, checking implementations against the paper, hunting silent bugs, keeping notes across sessions — and it stops at every decision that is actually yours. You decide; the machines execute. Claude Code does the work; Codex argues with it before anything reaches you.

Optional plugins

Propel uses these when they're present and works without them. They are never installed by propel init: a plugin can ship hooks, commands and MCP servers, so it runs code in your session — that's your call, not a side effect of setting up a project.
